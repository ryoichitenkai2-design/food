# Lazy Bulk (iOS)

1. Create a GitHub repo and push this folder to the `main` branch.
2. Open the repo's **Actions** tab, run **Build IPA** (it also runs on every push).
3. Download the `LazyBulk-ipa` artifact and unzip it to get `LazyBulk.ipa`.
4. The IPA is **unsigned**. Sign and install it with Sideloadly or AltStore on your Windows PC using your Apple ID. Free Apple IDs expire after 7 days and need re-signing.

Requires iOS 17+. Calories, protein and prices are rough estimates.
